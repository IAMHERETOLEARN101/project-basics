# Example JSON

These are synthetic documentation templates, not executable configuration or supported API schemas.

- project-config.example.json: local project preferences without credentials or service identifiers.
- analysis-request.example.json: a generic analysis request using fictional columns.
- permission-review.example.json: a fictional read-only permission review with writes disabled.
- driver-plan.example.json: fictional availability and a planning goal, without location or trip history.

Values such as demo-user-001 are invented identifiers. Replace values only in ignored local files. Do not add real organization names, endpoints, records, or authentication information.
