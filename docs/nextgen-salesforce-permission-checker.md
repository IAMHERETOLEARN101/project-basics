# NextGen Salesforce Permission Checker & Assigner

The [development demo](https://development.d1b6qlf1i3o8kg.amplifyapp.com/salesforce.html) lets you select a sample user, see where permissions come from, and preview a permission set assignment or removal. Changes apply to sample data in the current browser tab.

The next milestone is to verify a read-only permission lookup in a Salesforce development org. The native Lightning interface is in development for eventual distribution as a managed package. The Slack permission checker is planned as a separate app from NextGen SalesBuddy.
